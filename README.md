# 🌱 Agrinho 2026

**Sustentabilidade no Campo**

Um projeto dedicado à promoção de práticas agrícolas sustentáveis, inovação tecnológica e desenvolvimento social no setor agrícola.

## 📋 Sobre o Projeto

O Agrinho 2026 é uma iniciativa que busca transformar a agricultura através de:

- 🌾 **Agricultura Sustentável**: Práticas que preservam o meio ambiente e garantem produtividade
- 💚 **Compromisso Ambiental**: Redução de emissões de carbono e proteção da biodiversidade
- 👨‍🌾 **Desenvolvimento Social**: Capacitação de agricultores com conhecimento e tecnologia

## 🎯 Objetivos

1. **Educação** - Disseminar conhecimento sobre práticas sustentáveis no campo
2. **Inovação** - Implementar tecnologias modernas e ecológicas
3. **Crescimento** - Expandir o impacto positivo em toda a comunidade agrícola
4. **Impacto** - Criar um legado sustentável para gerações futuras

## 💻 Estrutura do Site

```
Agrinho-2026/
├── index.html          # Página principal do site
├── styles.css          # Estilos e design
├── script.js           # Interatividade e funcionalidades
└── README.md           # Documentação
```

## 📁 Arquivos do Projeto

### index.html
Página principal com as seções:
- **Navegação**: Menu de navegação fixo
- **Hero**: Seção inicial inspiradora
- **Sobre**: Informações principais em cards
- **Objetivos**: Timeline dos objetivos
- **Contato**: Formulário de contato
- **Rodapé**: Informações finais

### styles.css
- Design responsivo e moderno
- Paleta de cores verdes (sustentabilidade)
- Animações suaves e efeitos visuais
- Compatível com dispositivos móveis

### script.js
- Scroll suave entre seções
- Validação de formulário
- Animações ao fazer scroll
- Efeitos interativos

## 🚀 Como Usar
